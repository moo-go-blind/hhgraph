# hhgraph：手指衛生ダッシュボード（汎用版）

手指衛生の月次データ（消毒薬の本数、延べ患者数、遵守率）を入力して、推移をグラフと表で確認するためのダッシュボードです。HTMLファイル1つで動き、サーバーもネット接続も要りません。ベンチマーク（他施設や外部基準との比較）は含みません。

## 使い方

リポジトリ直下の `index.html` をブラウザで開くだけです（空の状態から始まります）。

GitHub Pages（[https://moo-go-blind.github.io/hhgraph/](https://moo-go-blind.github.io/hhgraph/)）は、開いてすぐ見られるようにサンプルデータを入れた状態で公開しています（`docs/index.html`）。実務で使うときはPagesではなく、リポジトリ直下の `index.html` を使ってください。

1. 「設定タブ」で、自施設に合わせてマスタを登録します。
2. 「入力タブ」で、月ごとに数値を入力します。
3. 「ダッシュボードタブ」で、期間と対象を選んで確認します。

データはブラウザの中（localStorage）に保存されます。別のPCへ移すときやバックアップには、設定タブの「データ」からJSONで書き出し・読み込みをしてください。

リポジトリ直下の `index.html` は空の状態から始まります。動作の見本を見たいときは、設定タブの「データ」からサンプルデータ（架空の施設「サンプル病院」、病棟4つ・病棟外2部署、19か月分）を読み込めます。GitHub Pages版はこのサンプルが最初から入っています。

## 設定タブ（左サイドパネル）

- 全般: 施設名、ライト/ダークテーマ、年度の開始月、既定の指標、移動平均、遵守率グラフの点表示、保存した期間プリセットの削除
- 消毒薬マスタ: 製品名、容量（mL/本）、1回量（mL）、本数の意味（請求／使用）
- 病棟マスタ: 病棟名、「一般病棟」に含めるかどうか（ICU・NICUなどを一般病棟の合計から外すための区分）
- 病棟外マスタ: 外来・手術室など、病棟以外の部署名
- データ: JSON書き出し・読み込み（設定とデータ全部）、CSV／Excel書き出し・読み込み（入力データだけ。月・区分・部署/病棟・製品・値の1シート形式で、Excelで開いて編集できます）、サンプルデータ読み込み、全消去

## 入力タブ

月を選んで、表形式で入力します。Excelからコピーした値をそのまま貼り付けできます。空欄は未入力として扱い、0とは区別します。

- 病棟・病棟外ごとの、消毒薬の本数（製品別）
- 病棟ごとの延べ患者数（患者日）
- 病院全体の入院・外来の延べ患者数
- 病棟ごとの遵守率（入室時・退室時の実施数と観察数）

## 表示のルール

- 期間は年度別プリセット（開始月は設定で変更可）、直近12か月、全期間、カスタム範囲から選べます。カスタム範囲には名前を付けて保存できます。
- 延べ患者数が入っていない期間は、患者あたりの指標を出さず、使用量・推定回数・本数の合計だけを表示します。
- 遵守率の入力がない期間は、遵守率のグラフと数値を表示しません。
- 患者あたりの値は、使用量と延べ患者数の両方がある月だけで計算します。

## 計算の定義

- 使用量（mL）＝ 本数 × 容量（mL）
- 推定回数 ＝ 使用量（mL）÷ 1回量（mL）
- 患者あたり ＝ 対象月の使用量合計 ÷ 延べ患者数合計（月の比率の平均ではありません）
- 遵守率 ＝ 実施数 ÷ 観察数。期間の値は実施数と観察数を合計してから割ります

## ファイル

- `index.html`：本体（実務用、空で開始）。これ1つで完結します
- `docs/index.html`：GitHub Pages用。同じ本体にサンプルデータの初期表示を組み込んだものです
